# pollution-map

แผนที่ควบคุมมลพิษแบบโต้ตอบสำหรับพื้นที่จังหวัดระยอง ใช้ MapLibre GL JS และแผนที่พื้นหลังจาก MapTiler พร้อมข้อมูลขอบเขตชุมชนในรูปแบบ GeoJSON

ความสามารถหลัก:

- เลือกและแสดงขอบเขตชุมชน
- วางจุดจากการคลิกหรือกรอกพิกัด
- วาดวงรัศมีตามระยะจริงเป็นเมตร
- เพิ่มลูกศรและข้อความประกอบบนแผนที่
- สลับแผนที่ถนนและภาพถ่ายดาวเทียม
- ทดลองพื้นที่ทำงานแยกหน่วยงานผ่าน `agency-demo.html`

การแยกหน่วยงานรุ่นทดลองครอบคลุมโครงการ จุด CSV ประวัติ CSV ชุดรัศมี ชั้นข้อมูล และผังชุมชน โดยแยกพื้นที่จัดเก็บในเบราว์เซอร์

รุ่นใช้งานจริงเริ่มที่ `login.html` และใช้บัญชี Google โดยไม่เก็บรหัสผ่าน รองรับบทบาทผู้ดูแลหน่วยงาน ผู้แก้ไข และผู้ดูข้อมูล ตรวจสิทธิ์และทะเบียนหน่วยงานจาก Google Sheet กลาง ส่วนไฟล์โครงการและผังชุมชนจัดเก็บใน Google Drive ของบัญชีที่เข้าสู่ระบบ การเปิดใช้ครั้งแรกให้ทำตาม `GOOGLE-LOGIN-SETUP.md` แล้วใส่เฉพาะ Google Client ID และ Apps Script Web App URL ใน `config.js` ห้ามใส่ Client Secret, access token หรือรหัสผ่านลงในเว็บไซต์หรือ GitHub
