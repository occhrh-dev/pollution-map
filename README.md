# pollution-map

แผนที่ควบคุมมลพิษแบบโต้ตอบสำหรับพื้นที่จังหวัดระยอง ใช้ MapLibre GL JS และแผนที่พื้นหลังจาก MapTiler พร้อมข้อมูลขอบเขตชุมชนในรูปแบบ GeoJSON

ความสามารถหลัก:

- เลือกและแสดงขอบเขตชุมชน
- วางจุดจากการคลิกหรือกรอกพิกัด
- วาดวงรัศมีตามระยะจริงเป็นเมตร
- เพิ่มลูกศรและข้อความประกอบบนแผนที่
- สลับแผนที่ถนนและภาพถ่ายดาวเทียม
- ทดลองพื้นที่ทำงานแยกหน่วยงานผ่าน `agency-demo.html`

การแยกหน่วยงานรุ่นทดลองครอบคลุมโครงการ จุด CSV ประวัติ CSV ชุดรัศมี ชั้นข้อมูล และผังชุมชน โดยแยกพื้นที่จัดเก็บในเบราว์เซอร์ ส่วนการใช้งานจริงที่ต้องไม่ให้หน่วยงานอื่นเห็นข้อมูล ให้ติดตั้งฐานข้อมูลและสิทธิ์ตาม `supabase/agency-schema.sql` พร้อมระบบเข้าสู่ระบบก่อนเปิดใช้ข้อมูลจริง
